The selected case brief uses a single title and three key fact groups. Response plan/Evidence separates decisions from source detail. The fixed response footer remains visible during panel scrolling. Map attribution and route access notes are visible/reachable. Tile imagery and the directed route are actual rendered product data.

Before: repeated same-weight facts and controls competed across the queue/map/inspector. After: coral fire, blue medical, amber access, violet safety, teal assistance and gray informational grouping; stronger queue/brief/plan hierarchy; amber unresolved review section and green completed action disclosure. Date/time shows live seconds and named Pacific timezone. No alarm animation, decorative hero imagery or fake metrics were added.

Interaction evidence: received-only projections, saved unit/route choices, real edge-excluding detour, unresolved route hold, exact reviewable wording/audience, caller return transport, browser persistence and human acknowledgment. Existing sources, corrections, replacements, recovery and simulator controls passed the regression suite. No decorative backend substitute was introduced.

Rubric (prototype scope): hierarchy 9/10, category clarity 9, readability/contrast 8, responsive organization 8, interaction integrity 9, evidence honesty 9, domain specificity 9. These are author QA judgments, not user-study scores. Residual: dense metadata and road labels need real operator usability testing; map navigation is a preview with bounded graph coverage. No serious/critical axe issues on tested selected workspace states; full assistive technology certification is not claimed.

Release verdict: ready to demonstrate the implemented local prototype. Real dispatch/traffic/navigation validation and external communications are separate future work.
