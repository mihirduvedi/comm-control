# Quiet shift desk QA

Compared the current app with the actual v3 baseline, using the same four city incidents. The new dark teal header, mist-blue queue, sage response pane and category-tinted brief reduce the large white surfaces. White now supports editable content and source reading. Unselected queue rows lose a redundant status line; Messages, automatic actions and history open when needed. The fixed Respond action stays visible.

Humanization covers operator/field/admin copy, labels, hints, errors, loading states, model value-style guidance and generated policy explanations. Decorative dot separators were removed. Original caller words, literal received excerpts, already-approved instructions, numerical facts and old audit records remain intact. Calculated distances use miles and short route steps keep useful precision. Device accuracy is shown in feet, rounded outward. Storage/road computation stays in meters and spoken/quoted units stay verbatim.

The live-call surface has its own provisional teal ring and Not reviewed label. A real hosted synthetic-microphone test showed a City Hall location during recording, with zero received reports or assigned units. Finished audio produced a source-linked draft; only operator review and actual selected-link receipt created the incident/assignment. A paused link held the report. This is a five-second snapshot workflow, not a streaming telephony service or human ASR benchmark.

Checked actual desktop1440/1280,800,390 and720×500 CSS-space workflows. Category and urgency have text/icon alternatives. Controls retain keyboard/focus/dialog behavior. Route data, map attribution, device geolocation isolation, evidence, correction, replacement, persistence, reconnect and manual recovery keep their backend outcomes.

Defect ledger:
- P1: Leaflet attribution could intercept the app notice close button. Fixed with map stacking isolation and the app notice layer; real click rerun passed.
- P1: Several quiet labels missed contrast on new tinted panels. Darkened inactive filter/map/resource and elevated labels. Retested city, legacy and live-call states with axe.
- P1: Opening live mode with an old fictional-site report could select the wrong map. Live mode now keeps the city map; a legacy-only regression setup verifies this.
- P2: Old exact selectors still used decorative separators. Migrated them to the reviewed labels while preserving source-quote assertions.
- P1: First intake implementation nested existing domain transactions. Moved boundaries around the existing atomic domain operations; tests now pass through preview/final/revision/send/cancel paths.

Author QA rubric: hierarchy9/10, color grouping9, readability8, responsive8, content clarity9, interaction integrity9 and evidence honesty9. These are author judgments, not operator-study results. Remaining product gates are actual human acoustics/speakers, assistive-device testing, unseen phrasing, operational road checks and real dispatch integrations. No in-scope engineering failure is accepted as a finished state.
