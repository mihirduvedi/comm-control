# Comm Control v5.1

Open `Open_Comm_Control.command` to launch the existing configured local app with private browser access. It opens the workspace directly; Live call opens capture when you choose it. The fresh chat access link is a one-use, 30-minute ticket. After opening, the same browser can reopen http://127.0.0.1:8765/control for eight hours. The server stays loopback-only.

The app now uses mostly white glass panels, blue borders, soft stationary blue background light, a floating rounded header and rounded controls. The dispatch divider and colored queue strips are gone.

There is no voice picker. Each demo person has a saved voice, and operator instructions always use the operator's voice. Actual call recordings keep their original audio. Generated fictional fixtures have speaker provenance; no voice cloning is involved. First generated playback uses Groq and is cached privately for replay.

The v5_1 source ZIP is current. It includes editable source, tests, built assets, Downtown LA data/attribution, fictional demo fixtures and docs. Private keys, runtime reports, installed dependencies and work caches are excluded. Follow its README to configure a new copy; the launcher opens the existing app on this Mac.

`Comm_Control_v5_1_Handoff_2026-10-17.md` is the continuation point. `Comm_Control_Demo_Guide.md` covers the pitch story, and `Comm_Control_Verification.md` states what passed. Old voice audition previews and v5 files are historical; the current app assigns voices automatically.

Submission finishing work remains your real microphone/speaker rehearsal, pitch recording and event-specific submission copy. No deployment, external dispatch or submission was performed.
