# Comm Control: submission rehearsal

Open the supplied launcher. It reuses the local server and opens an authorized browser. Your existing reports and link settings stay saved. If a new browser shows an access page, use the launcher again.

## A three-minute story

1. **Explain the problem (20 seconds).** “A voice report is useful only if the next person can see what was actually said, where it happened, and what still needs checking.” This is a local communication/operations demonstration with simulated units and transport.
2. **Take a live report (45 seconds).** Choose Live call, start the microphone and allow access. Say: “There’s smoke near City Hall. Two people are outside. I don’t know if anyone is still inside. Please send fire support.” Show the provisional place pin. Finish the call, check the facts, and add the reviewed incident. If the selected link is slow, explain the queued delivery rather than presenting it as received.
3. **Show the response (35 seconds).** The received incident has a real Downtown LA location, an available demo unit/route when possible, and an explicit occupancy question. Open Evidence and show the actual supporting words. Automatic assignment is a local policy decision, not real dispatch.
4. **Return exact words (35 seconds).** Respond with an exact written instruction, review it, approve and send. Open that caller’s private field view from Sessions. Choose a natural voice and Listen. Acknowledge receipt. Point out that acknowledgment hasn’t answered the occupancy question.
5. **Hand over and close (35 seconds).** Open Case history. Add an owner and handover note. Close incident, record the outcome and explicitly review outstanding items. Show the released demo resource and Closed filter. Download the case record. Reopen to demonstrate that history remains and the response plan is checked again.

## Before recording the submission video

- Use a rehearsal run for closure demos; keep existing actual app data unless you deliberately reset it. Automated tests use their own port/data directory.
- Listen once to Hannah/Troy/Autumn and choose the voice you prefer. These are generated voices; use your own microphone recording if you want a real human caller.
- Have internet available for fresh AI and map tiles. Previously generated recipient audio, local road routing and saved records can work without provider access. The local server must still run.
- Keep the Groq account on Free. The app makes no account upgrades and has no paid fallback. A limit/failure is shown explicitly.
- Turn on demo automation in Setup if you want automatic assignment. Choose the link profile deliberately in Simulator. The app preserves these settings, including pauses.
- Have four free caller slots before queuing the city scenario, or use an existing caller. Don’t reset an important run merely for a cleaner screenshot.
- Show the simulation boundary once. No emergency phone line, SMS, physical radio, public alert or agency dispatch is connected.
