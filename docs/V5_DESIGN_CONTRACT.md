# Daylight desk

The audience is a hackathon judge or an operator trying the local demonstration. The map stays central. The queue, facts and response are work areas rather than a marketing dashboard.

The user chose a lighter, happier blue and then asked for a floating rounded header. A pale sky navigation bar now floats on the blue canvas, aligned with the panel margins. Blue ink maintains contrast. The queue is the lightest reading surface, and the response area is a quiet blue sheet. Fire, medical and access colors keep their semantic roles. No decorative gradients, new icon tiles or unnecessary motion were added.

Dominant rule: align information to the map/queue/response columns. Counter-rule: let category-specific incident evidence retain its own color. Signature: the floating sky bar above a working street map. Creative risk: a light control-center palette rather than a dark emergency-console treatment, justified by the user's explicit preference and maintained contrast.

Existing system typography is retained for recognizable native controls. Installed alternatives inspected included Avenir/Avenir Next and the Apple system family. System text was chosen for dense data and avoids a new font dependency. Headings use weight/spacing rather than an ornamental display face.

Source text, original quotes, old audit records, approved instructions and proper names remain literal. New case copy uses concrete actions and consequences. Natural voices are labeled generated, and source recordings are never impersonated or replaced. Saved synthetic fixture assets are separately labeled and have provenance.

Behavior contract: the new Case history tab reads only received evidence. Notes bind a report version. Closure requires an outcome note and explicit review of open items; it releases local demo resources but preserves sources, unanswered questions, road reports and actual delivery state. Reopen reconstructs a response plan using the existing policies. Downloads contain only the selected caller's received records and operator notes. Natural playback submits unchanged text to the existing provider, within the existing Free-tier guard. Failure offers explicit local playback rather than an invisible voice change.
