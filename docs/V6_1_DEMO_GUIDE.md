# Comm Control v6.1 demo rehearsal

1. Open Workspace with the local launcher. Use New test in Resources if you want a clean city, campus or empty test; the current run is archived first. Do not reset just to inspect the UI.
2. Point out the priority queue. Explicit immediate threats rise above routine assistance. Expand evidence to show the exact words and remaining uncertainty. Demonstrate a manual drag, then Use priority.
3. Choose Live call → Start microphone. Say a short report with an unambiguous event location inside the mapped area. Stop, check transcript and location, and send. The live flow creates the session. For unreliable microphone permission, use the typed source fallback honestly; do not present typed or prerecorded input as a live microphone result.
4. For aggregation, make a second fire report at the same event location within 30 minutes. The queue shows one incident with linked reports. Open it to show both callers and new facts, such as an injury. In city mode this can add medical coverage without assigning a second fire unit. Use a reason when linking or separating manually.
5. Open Resources. Show unit stages, assignments by area and route estimates. Mark a unit en route, then on scene. Assigned and en-route markers are simulated bases or operator-marked arrivals, not GPS telemetry.
6. A blocked-road report changes subsequent city routes. A stale closure stays excluded. Clear it only with a later matched report or the reviewed manual control. Show the saved source and route change rather than claiming live traffic.
7. Choose Fictional campus. Select a building, toggle responders and paths, and inspect the separate roster. Gate updates require a reason. Paths avoid blocked gates and hold when no open route remains. Drawing units have no physical ETA.
8. Show New test and Saved tests. Type the requested phrase only when you actually want to change the current run. Restoring preserves history and source references in the local private runtime; exports omit that private data.
9. Finish with source evidence and approved caller messaging. Prepared wording still requires review. Record the submission video using your actual mic and speakers, and make final submission wording match what you demonstrated.

Provider extraction/readout and map tiles need internet. Cached city roads and authored campus paths run locally. Hosted checks from v6 are prior evidence; the v6.1 release regression suite does not spend new model calls. The model terms were accepted by the user, and no legal agreement was accepted by the agent.
