# Comm Control v6.1

Open [Workspace](http://127.0.0.1:8765/control) or [Resources](http://127.0.0.1:8765/resources). A fresh browser may need `Open_Comm_Control.command` first to authorize access.

For a new live call, choose **Live call → Start microphone** from Workspace. It creates the reporting session for you. Stop when finished, check the transcript, threats and event location, then send the reviewed report. A mapped, received report can reserve suitable demo units. The caller’s current position does not substitute for the event location.

**New test** appears in Resources, Setup and Review. Choose Downtown LA defaults, fictional campus or an empty workspace, then type START NEW TEST. The app saves the current run before resetting reports and demo settings. Open Saved tests in the same dialog to restore it; restoring also saves the current run first. Your provider credentials, browser access, fixed speaker voices and rolling request budget remain. Do not remove the private runtime folder if you want to retain these saved runs and source audio.

Related fire and access reports at the same place can join one incident. Open the linked-report control to read every caller’s details, link another report or separate a mistaken match. Medical and safety calls require manual linking. Linking does not verify a claim or replace source evidence.

The queue starts in priority order. Drag a row or use its up/down controls to arrange it manually. **Use priority** restores automatic ordering. The change affects display order, not the report’s assessed severity.

Resources shows unit readiness, capacity by type, assignments, routes, coverage gaps and a saved roster. Select **Fictional campus** for its separate responders, map layers and gate controls. Campus paths use the authored drawing; they do not claim physical distance or arrival time. City routing uses cached Downtown LA roads and excludes reported closures until a matched later clearance or manual reopening.

Body text now uses locally hosted IBM Plex Sans, with the existing bold system headings. White reading surfaces, restrained blue borders and rounded glass chrome remain.

This is a local hackathon demo with simulated resources. No real dispatch, phone network or agency integration is connected. Ranking uses improved prompts, source checks and review rules; no model weights were trained. Read the verification file for current test evidence and the handoff for implementation details.
