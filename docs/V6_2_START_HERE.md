# Comm Control v6.2

Open [USC facilities](http://127.0.0.1:8765/resources?view=usc) or [Workspace](http://127.0.0.1:8765/control). A fresh browser may need the existing Mac launcher first.

USC is now the only campus view. Its custom plan uses actual OSM building footprints and outdoor paths, with no satellite imagery or tile dependency. Start at the closer view, look up a building, or use Fit campus for the wider access-point view. Arrow keys pan a focused map; plus/minus zoom. Access points, paths and teams can be toggled. The city map remains available for Downtown LA incidents.

To rehearse the facilities demo, open **New test → USC facilities**. Starting the test saves your current run first. Six explicitly simulated reports cover tank pressure, a gas concern, a smoke alarm and maintenance. Do not reset merely to inspect the new map. Your existing reports remain, and the old fictional map has been removed. A past warehouse report can be associated with a USC building through **Locate at USC**, with a recorded reason; its source stays unchanged.

The header's **Live call** button opens intake from any page. Start microphone, stop, check the transcript and event location, then add the reviewed report. USC building names/codes can be recognized; keep the location unconfirmed if it is unclear. Received confirmed reports create campus work items and appropriate simulated team assignments. Original recordings, facts and replies remain accessible in Evidence. Add a report on the facilities page is an explicit manual-source alternative.

Pressure updates for the same identified demo tank share a work item and preserve reading history. Review limits are operator-set demo ranges, not equipment specifications. Unknown tank identities are kept separate. Alarm and gas concerns retain their original assertion and source text. No sensor, valve, campus team or external service is connected.

The middle panel scrolls over both maps. While dragging a queue row, hold near the top or bottom edge to auto-scroll and drop at the desired position. Manual order persists; Use priority restores ranking. Selection outlines slide across tab bars, respecting reduced motion. Body text now uses the same system font family as the titles, in regular/medium weights.

Remaining submission work: rehearse with your actual mic and speakers, record the demo and prepare the event-specific submission. The handoff and verification file contain the exact implementation scope and evidence.
