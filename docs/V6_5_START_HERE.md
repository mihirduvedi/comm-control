# Comm Control v6.5

Open [USC campus](http://127.0.0.1:8765/control?world=usc) or [Downtown LA](http://127.0.0.1:8765/control?world=city). Use the Mac launcher for a fresh authorized browser session if needed.

The main action is **Start voice report**, available on every operator page. You do not need to create a reporting session first. Record a call, finish, review the transcript and event location, and choose **Add reviewed incident**. The received report drives categorization, location mapping, appropriate demo team assignment and a route around known blockages. Unknown locations or unavailable resources remain pending. Assignment follows the enabled automation settings and available capabilities.

Each selected incident now shows the actual state of its details, location, team and route above the map. Annotated City inputs are labeled as demo reports. Manually annotated USC fixtures retain their Manual report source label; voice and typed reports have their own labels. These status labels do not perform or bypass any operation.

The workspace uses one document scroll outside the maps, so all three columns move together. Scrolling over a map zooms it. The wider queue keeps its own bounded list for browsing and dragging large numbers of incidents; dragging near either edge scrolls that list. The response tabs have more top inset and no horizontal divider. Panels have full borders and a soft surrounding shadow. City and USC keep their shared font, colors, tags and rounded surfaces.

USC contains six fictional reports at real buildings, grouped into five routed work items. Two SGM pressure updates share one work item while preserving both sources. City and USC reports, resources, sessions, alerts and queue orders stay separate. All source quotations remain intact.

Use **New test** in Resources to save and restart the complete local run. Saved tests restore it. The update itself does not reset your run. **Load USC demo** or Simulator replays the campus scenario in an empty USC world.

This remains a local coordination demonstration with simulated teams and incidents. New audio uses the configured Groq provider. Cached public geometry provides route previews, not verified indoor exits or current gate access. The current changes add no phone integration, real dispatch or model-weight training.
