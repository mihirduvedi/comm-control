# Comm Control v6 — Operations atlas

A dispatch operator should be able to find the most urgent source claim, verify its event location, and see which demo resources are covering it without opening several competing panels.

## Composition

The map is the main working surface. The left column is a compact incident ledger; the right column is a response plan with secondary communication and audit tools behind disclosures. Resources gets its own page: one count strip, a map beside area allocations, then the unit ledger and waiting cases. Whitespace separates jobs and makes map geography legible; it is not filled with decorative statistics.

Three structures considered: a dense CAD-style grid (too much competing information), a gallery of glass cards (too repetitive and disconnected from the task), and an atlas with narrow ledgers (chosen). The controlled counterpoint is the rounded, translucent navigation and map labels requested by the user. Operational reading surfaces remain almost white. No new decorative raster assets or generated imagery are useful here.

## Type and materials

Avenir Next was tried and rejected by the user as too broad and bubbly. Restore the original Apple/system sans stack, 400 body, 500 numbers, 600 headings. Use restrained tracking on headings and tabular numbers for counts/times. Primary blue #2869ae, near-white #f8fafc, blue-gray edges #bcd0e4. Color carries state in small labels and map marks; no queue stripes or broad colored category pills. Glass is concentrated in the header and map controls rather than every inner row.

Navigation links must be centered within the floating bar, with one active pill and no inherited underline. At desktop, the selected pill's center must be within 2 px of the header's center. Keyboard focus remains visible. Below 1024 px, preserve the existing Queue/Map/Details navigation rather than shrinking three columns. Resources stacks below 650 px, with compact count columns and a readable roster. Support reduced motion/transparency.

## Humanized copy

Use direct labels: Resources, Unit roster, By area, Response plan, Waiting for coverage. Avoid motivational dashboard titles, machine architecture in headings, and vague “no suitable route” explanations for busy units. Keep simulation and source-review qualifications wherever they affect an operator decision. Source quotations, names, literal facts and legal/transport meanings stay verbatim. Copy inventory is V6_UI_COPY.md.

## Acceptance

No queue stripes or horizontal dispatch separator. No voice picker: one fixed voice per speaker. No overflow at 390/800/1280/1440. Map remains keyboard usable and retains source positions/routes when tiles fail. All resource controls change persisted demo state. Area totals come from active assignments. Lost API connectivity shows last saved values and disables changes. Serious/critical axe findings must be repaired. Visual review of the actual rendered workspace and Resources is required in addition to automated checks.
