# Comm Control v6

Open **Open_Comm_Control.command** on this Mac. It starts or reuses the existing local server and opens an authorized browser. In the browser already open, use http://127.0.0.1:8765/control or http://127.0.0.1:8765/resources. Plain links in a fresh browser may need the launcher first.

Threats are ranked with exact source evidence. Finished live calls have an event-location review and an explicit location hold. Received, located reports can allocate suitable available demo units. Resources shows saved counts by type/place, routes, waiting cases and a roster you can update. Earlier blocked-road reports affect future routes until an explicit matched clearance or manual reopening.

The header is centered, the original system font is back, and the map has more room. White/blue rounded glass, fixed speaker voices and source recordings are preserved. All nine saved reports remain.

This remains a local demo with simulated units. AI and map tiles need internet; routing covers the cached Downtown LA graph. The ranking work improved prompts, semantic checks and review policy; model weights were not trained. At the final hosted-check audit, 4 requests remained in the app's rolling 60/hour budget. Saved demos, cached audio and local resource controls still work without another model request.
