# Project imagery

Product screenshots are actual Comm Control prototype captures using fictional reports, callers and teams. They aren't generated interface mockups. The resource overview is a crop of the full resource page; its contents haven't been retouched.

The hero is an original vector composition around a preserved campus screenshot. The poster combines original vector typography and conceptual map illustration with a prototype screenshot. Its extrusions and drawn route aren't a surveyed building model or operational navigation result.
